# SAIDS 

## 1 Step = 1 Cell in Jupyter Notebook

Complete each experiment by writing **one step in one Jupyter Notebook cell**. Execute each cell using `Shift + Enter` and proceed to the next step.

## Install Jupyter Notebook and the Required Libraries

**Step 1:** Open your Terminal in macOS.

**Step 2:** Paste and execute the following command:

```bash
python3 -m pip install notebook numpy pandas matplotlib seaborn scipy scikit-learn
```

**Step 3:** Launch Jupyter Notebook

**Step 4:** Create a new Python notebook and start performing your experiments, following the **1 Step = 1 Cell** rule.
